常见问题

Heybe 免费吗？

免费。Heybe 社区版以 Apache-2.0 开源。以后会推出功能更多的付费 Pro 版，价格尚未公布。

现在能下载吗？

还不能。开发者预览版正在开发中。加入候补名单，准备好后我们会发邮件通知你。

我的数据会上传到云端吗？

Heybe 在你的 Mac 上运行，文件留在本机。思考部分由你选的 AI 服务完成（默认 DeepSeek，或用你自己的 OpenAI、Claude Key）；想完全离线，也可以用本机模型。

能用自己的 OpenAI 或 Claude API Key 吗？

可以。支持自带 OpenAI 或 Anthropic Claude 的 Key，Key 存在 macOS 钥匙串里。

它会不经同意就做事吗？

不会。删除文件、超出预算等敏感操作都要等你点击确认。第一版不会替你发邮件、发帖或付款。

Heybe 能替代 Manus 或 ChatGPT Agent 吗？

它做的是类似的事：把多步骤的活交出去。不同的是它在你自己的 Mac 上运行、开源，并且 AI 由你来选。

需要什么设备？

一台 Apple 芯片的 Mac（M1 及以上），不支持 Intel Mac。第一版不支持 Windows。安装包只在 heybe.dev 提供，不上 Mac App Store。

需要懂技术吗？

不需要。会发短信，就会用 Heybe。
