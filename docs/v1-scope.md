# Heybe v1 范围（D1–D6 均已确认；2026-10-23 经 Yang 通过 Grok Bot 冻结）

> 品牌 Heybe（原代号 OpenGrok / HeyBe），域名 heybe.dev。公开仓库 Slovian42/Heybe，私有仓库 Slovian42/Heybe-Pro。
> 决定 D1–D6 均已确认，见第 6 节。本文于 **2026-10-23** 冻结；确认人 Yang（经 Grok Bot）。自该日起，开发者预览 v1 范围以本文为准。编号格式：`#n` = Slovian42/Heybe 的 Issue，`T/E` = backlog.md 中的条目。

## 1. 一句话范围

v1 = **Mac、单用户、以 LLM 为核心的 Heybe 开源版（开发者预览）**：用户在自研桌面应用（Tauri+React）里连上自己的模型，和一个助理聊天、联网查资料、交办一件单人任务并拿到本地文件。默认开启沙箱。不托管、不代管 key、不含 Pro。

对应 backlog 阶段 0 + 阶段 1 全部，加上从阶段 3、5 前移的少量"最小可用"件（下文标【前移】）。

开发者预览 v1 不包含 Telegram 及其他 IM 聊天渠道；这些渠道在 v1.1 交付，采用已决定的自托管桥接方案 C。长期共享记忆仍按决策 D2 延后，不进 v1。

## 2. v1 出关标准（签字即视为验收口径）

1. 新用户在干净 Mac 上，不打开 FastClaw 控制台，10 分钟内完成首次对话（见 flows-spec.md 流程一）。
2. 默认云模型 DeepSeek 开箱可用，用户自带的 OpenAI、Claude key 连接测试通过（其余提供方按 #16 验收）；只用 Ollama 时可离线多轮对话。
3. 10 个联网问题中至少 8 个来源正确（首发通过直接抓取网页实现，不依赖 Exa）。
4. 关闭窗口不丢任务；失败不显示为成功；产物不合格时停在"待你确认"状态。
5. 沙箱默认开启，越权读写和越权联网被实际阻止，有测试证据。
6. 仓库、日志、导出包中没有明文密钥。
7. 所有合并提交通过 DCO 检查。

## 5. 不做（明确排除）

- 使用 FastClaw 自带前端，或依赖 `/api/*` 内部接口（确实需要时只在适配层中使用，并单独签字）。
- 关闭沙箱的"高级模式"。
- 本地模型的工具调用承诺（只写文档建议）。
- Windows 和 Linux 桌面版。
